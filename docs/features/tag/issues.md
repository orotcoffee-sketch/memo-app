# 태그 기능 이슈

근거 문서: [prd.md](./prd.md)

두 이슈는 각각 그것만 끝나도 화면에서 확인할 수 있다. 이슈 2는 이슈 1의 태그 칩 위에서 동작하므로 이슈 1을 먼저 한다.

## 이슈 1. 메모에 태그 추가/삭제

본문에 `#태그`를 쓰면 메모 아래에 태그 칩이 나타나고, 태그가 없어지면 칩도 사라진다.

완료 체크리스트
- [ ] 메모 본문에 `#업무`가 있을 때 메모를 추가하면 메모 아래에 `#업무` 칩이 보인다.
- [ ] 본문에 `#Work #work`처럼 대소문자만 다른 같은 태그가 있을 때 메모를 추가하면 `#work` 칩이 하나만 보인다.
- [ ] 본문에 `#a-b`가 있을 때 메모를 추가하면 `#a` 칩만 보인다.
- [ ] 본문에 `#`이 없을 때 메모를 추가하면 칩이 보이지 않는다.
- [ ] 태그가 달린 메모일 때 삭제 버튼을 누르면 메모와 그 칩이 함께 사라진다.

## 이슈 2. 태그 클릭으로 메모 필터

태그 칩을 누르면 그 태그가 달린 메모만 보이고, 상단 개수도 그에 맞게 바뀐다.

완료 체크리스트
- [ ] `#업무` 메모와 `#개인` 메모가 섞여 있을 때 `#업무` 칩을 누르면 `#업무`가 달린 메모만 보인다.
- [ ] 필터가 켜져 있을 때 같은 칩을 다시 누르면 필터가 풀리고 전체 메모가 보인다.
- [ ] 필터가 켜져 있을 때 `MemoCount`에 필터 결과 개수가 표시된다. (예: 전체 5개 중 2개면 "총 2개의 메모")
- [ ] 필터가 켜져 있을 때 선택된 칩은 다른 칩과 구분되어 보인다.
- [ ] 필터가 켜진 태그의 메모를 모두 삭제하면 필터가 풀리고 남은 메모가 보인다.
